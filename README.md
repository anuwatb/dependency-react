A tool for creating and editing dependency diagrams. Editors can create, edit, and delete diagram nodes and links. Users can view and update node statuses.

## Tech Stack

- Next.js

- Tailwind CSS

- TypeScript

- D3.js

- MongoDB

- Mongoose

- Neon: Postgres backends for apps and agents

- Drizzle ORM

- Zod

- Docker

- Google Stitch

- CodeRabbit
